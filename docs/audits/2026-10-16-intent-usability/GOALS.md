# Product goals versus current proof

Civis is a persistent game-first systemic sandbox. A player should understand a living world's constraints and act through fluid but meaningful god, leader and individual roles. The world must retain evolved social/cultural/physical state, not merely regenerate a seed. Rendering, assets, animation, audio, input and coherent controls are product obligations alongside simulation correctness.

| Goal family | Existing source / dated evidence | Current acceptance and missing proof |
|---|---|---|
| Living settlement and systemic consequences | Engine, scenario and simulation FR implementation; emergence oracles exist | One actual water/food constraint and causal response visible to player; outcomes and clarity not newly qualified |
| God intervention | God-tool specification, RPC/playthrough surface | Effect and authority scope must affect current world without inventing results; player witness open |
| Leader direction | Role/command intent and client/control surfaces | Selection/intent/control continuity through role switches; source presence alone insufficient |
| Inhabit affected person | Multi-role accepted journey | Same person, needs and consequences across switches; responsiveness and intelligibility unqualified |
| Native presentation/content | Bevy/Godot/Unreal attach paths and renderer/terrain FR rows | Installed selected client with real required assets/animation/audio; primitive fallback cannot silently stand in for accepted content |
| Save/quit/reopen | Save bundles, slots/autosave, metadata and RPC source; open1596/1569 save work | Evolved factions, relations, culture, mod/AI and world state reconcile after reopen; complete restart witness open |
| Background world continuity | Tick/session/replay systems | Bounded unattended resource/time run with source-backed changes and no fabricated event summary |
| Long-lived world and progression | Knowledge/technology/life/planet/economy/social FR families | Finite supported scenario/profile and causal dependencies need denominator and independent oracles |
| Mod/content iteration | Partial mod packages, signatures and runtime surfaces described in AGENTS | Full modding platform explicitly outside current lane; capability/security scope must be decided before expansion |
| Reliable delivery | Quality manifest, compile/security/FR workflows and releases | Named required checks are empty; actual sampled runners hosted; native playthrough fails; installed artifact provenance unqualified |

Main's 3D matrix labels many FRs implemented and includes test names. Those labels are useful traceability, not independent proof of current native gameplay. Historical determinism/research language does not override the game-first intent; determinism is a tool for suitable profiles, not a universal prohibition on useful concurrency.

Finite scope for the estimates: one selected shipping native client, one nontrivial living settlement and accepted scenario/content profile, all three roles, complete evolved-state save/recovery, bounded unattended evolution and the selected authoritative FR denominator. Larger world scale, every renderer/platform, unlimited cultures/tech trees or future player feedback are not silently included. They remain preserved backlog with explicit re-estimation.

# Strict civilian ECS snapshot primitive

This opt-in primitive captures a bounded subset of current ECS entity state without touching the existing save API. It accepts only supported civilian component types, refuses unsupported components, external entity alignment, oversized entity indexes, and malformed or duplicate identities. It constructs a new isolated world after validation; a failed capture or restore does not alter the source world.

Its contract is current component and entity identity only. Faction identifiers are not resolved against a faction registry, and `OtherEntity` alignments are rejected. It does not preserve the hecs allocator free list, future entity allocation, non-ECS simulation state, queued work, RNG, scene generation, or references held elsewhere. It must not be described as a complete simulation save or wired to `save.slot` as such. JSON input and output are capped at 16 MiB; duplicate keys and unknown nested fields are rejected, and DNA is capped at 64 KiB. The API cannot recover allocator history or validate faction identity. A seed-42 default simulation contains non-civilian entities and is rejected; it is not an acceptance witness for the normal game.
